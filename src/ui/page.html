连接排查与跨域设置
  1. 在浏览器中打开上方服务器地址，确认能进入 ComfyUI。若服务运行在另一台电脑上，请填写那台电脑的 IP 和端口。
  2. 若能打开 ComfyUI，但本页仍提示跨域错误，可在 HTML 所在目录运行 python3 -m http.server 8000 --bind 127.0.0.1，然后打开 本地工作台。
  3. 在 ComfyUI 启动参数中添加 --enable-cors-header http://127.0.0.1:8000，重启服务，再测试连接。使用其他网页来源时，请将参数改为该网页的实际来源。
