# 运行与验收

## 浏览器与 ComfyUI 接口

- 连接测试读取 `/system_stats`，工作流经 `POST /prompt` 提交。使用一份独立的任务快照，记录实际返回的 `prompt_id` 和请求服务器。标准 ComfyUI 可通过 `/upload/image` 上传本地素材，加载节点用响应的 `subfolder/name`，以响应为准。
- `/ws?clientId=…` 显示本页提交的执行事件。`/queue` 和 `/history/{prompt_id}` 负责恢复、轮询和收尾。导入外部任务时匹配主输出图结构和关键模型字段。按 ID 轮询这些任务，避免占用原客户端的 WebSocket。任务列表只显示当前服务器的本地记录，并在切换地址后刷新服务器队列。其他服务器中已跟踪的任务继续更新。状态页签只筛选当前服务器的数据，页签计数随状态变化同步更新，批量操作限于当前页签中勾选的任务。任务行之间用横线分隔。服务器返回的是 API 节点图时才有足够信息自动匹配。
- 服务器支持时按任务 ID 调用 `/api/jobs/{id}/cancel`。兼容路径针对排队项调用 `POST /queue` 的 `delete`，对已确认在运行的任务调用带 `prompt_id` 的 `/interrupt`。以队列、历史或中断事件确认结果。持续失联时只显示「已停止跟踪」。
- 根据实际 `history.outputs` 构造 `/view` URL，把 `filename`、`subfolder`、`type` 编成查询参数。VHS 的视频可能列在 `gifs` 下。成功、失败和取消的任务均可展示详情并复用有保存的输入。播放器可点击蒙版关闭，播放器内部操作保持可用。删除、移除和关闭操作使用警告色。旧任务本地快照缺失时，按原服务器和任务 ID 读取历史中的 API 图，恢复可确认的提示词、参数和参考图。补读详情和加载视频独立执行。保留已恢复的快照，避免旧记录在下次刷新时覆盖它。普通删除只移除网页任务记录和浏览器媒体缓存。
- 直接打开 HTML 时，连接仍受浏览器跨域访问约束。在跨域部署里让 ComfyUI 的 `--enable-cors-header` 接受页面实际来源，或经同源反向代理访问。浏览器目录写入受 File System Access 支持和用户授权约束。模板已带测试入口与排查说明。

## 每次交付至少核对

1. 文件为独立 HTML。工作流与映射用 JSON 脚本块安全嵌入，CSS、JS 和 ICO 内置。浏览器可加载且无脚本错误。桌面和手机宽度下主要控件可达。切换主题时保留当前草稿、参数和任务选择。
2. 在模拟 API 或授权服务器上截获 `POST /prompt`。至少核对原始默认值未漂移，已修改的参数作用在正确字段，两次连续提交使用各自快照。存在素材时验证页签计数、多文件导入和刷新恢复，再逐类验证实际上传路径、A、B、A 的重复引用和槽位顺序。混合图片、视频和音频时验证三个标签序列各自从 1 开始。
3. 模拟运行和终止，检查同工作流导入、ID 去重、错误展示、取消确认以及完成后的媒体展示。改动现有模板的对应区域时，再覆盖详情回填、批量下载 ZIP 和本地记录删除等功能。
4. 支持按分镜时长的工作流可打开项目批量入口。选择含 prompts 和 assets 的目录，核对时长来源、按类型编号、同名冲突、超限跳过及先预检后提交。共用素材的上传路径只在同一个服务器上的同一批任务中复用。
5. 最终说明验证的是模拟 API、实际连通，还是已经运行真实模型。代码存在并不等于安装了对应自定义节点和模型。
