## 按用户澄清回退：统一为浏览器原生文件夹选择器

- 用户反馈：只要"点选择文件夹 → 弹系统目录框"，服务端目录浏览器属于过度设计。
- 回退/删除：`workspace/server.py` 的 `GET/POST /workspace/dirs`、`page.html` 的 `#dirDialog`、`base.css` 的 dir-* 样式、`settings.js` 的 loadDirs/createDir/loadOutputs/saveOutputsPath 与 `#outputsPath` 路径输入。
- 统一方案（两种运行模式一致）：
  - `settings.js`：`#pickDirectory` → `window.showDirectoryPicker()` 系统弹窗；句柄（FileSystemDirectoryHandle）存**浏览器 IndexedDB**（全局 key `frameform.output-directory.v1`，兼容旧 `directory:<pageKey>`），不能用 `fileData`（hosted 下会 POST 给服务端且句柄不可克隆到服务端）；`#clearDirectory` 清除；每次打开设置重读句柄。
  - `workspace-runner.js`：sync 检测任务新变 done（非首次同步、之前非 done）时调用 `saveOutputs`，托管模式页面也能写入选定目录；首次全量同步不触发，避免刷新后重复保存。
  - `outputs.js`：`outputBlob` 改走 `resultURL`（托管模式经 `/workspace/result` 代理，避免直连 ComfyUI 跨域）；`saveOutputs` 无视频时保存首图（纯图片工作流也会自动保存）。
  - 服务端保留 `./outputs` 可读副本归档（默认值，`--outputs` 可改），settings API 保留但不再有 UI 入口。
- 测试坑：`#openSettings` 的 onclick 是 async（先读 IDB 再 showModal），点击后立即断言会 flaky，要用 `wait_for(state="visible")`；project_batch 的素材文件夹断言同理改成 wait_for（saveOutputs 增加 IDB 竞争拖慢面板渲染）；Playwright async 的 `download.value` 需 await。
